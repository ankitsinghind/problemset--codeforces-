# Codeforces Problemset Solutions

Welcome to my **Codeforces Problemset Solutions** repository!  
This repo contains my solutions to various Codeforces problems, written in **C++**.  
It serves as both a personal archive and a resource for fellow programmers who want to learn different approaches to competitive programming problems.

---

## File naming convention: 
`ProblemID.cpp` or `ProblemIDalternate.cpp`
- Each file contains a **self-contained solution** with input/output handling as per Codeforces requirements.

---

## How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/ankitsinghind/problemset--codeforces-.git
   cd problemset--codeforces-
   ```
